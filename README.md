# NOVA ✨

**NOVA — مساعد ذكي لكل حاجة (من تطوير محمد نبيل النجار)**

تطبيق ويب تقدّمي (PWA) للمذاكرة: بنك أسئلة من المنهج، توليد أسئلة من ملاحظاتك بالذكاء الاصطناعي، مساعد ذكي بالكتابة والصوت، وخطة مذاكرة يومية بمراجعة متباعدة.

🔗 التطبيق لايف: https://tutora-app.netlify.app

## المميزات
- بنك ١٨٨ سؤال اختيار من متعدد من منهج البرمجة والذكاء الاصطناعي (٧ وحدات)
- توليد أسئلة جديدة من أي ملاحظات (ذكاء اصطناعي مجاني، بدون مفاتيح)
- مساعد ذكي بالكتابة أو الصوت (الميكروفون بإذنك)
- خطة مذاكرة ذكية بمراجعة متباعدة + عداد أيام متواصلة
- وضع ليلي/فاتح، نغمة افتتاحية مع زر كتم، صفحة إعدادات
- يشتغل بدون نت بعد أول فتحة (Service Worker) — الذكاء الاصطناعي بس هو اللي محتاج نت
- الخصوصية أولًا: كل بياناتك على جهازك (localStorage)، مفيش حسابات ولا تتبع

## التقنية (للتعلم)
- React + TypeScript + Vite — بدون أي باك إند
- `src/data/` بنك الأسئلة (ملف لكل وحدة)
- `src/ai.ts` طبقة الذكاء الاصطناعي (توليد أسئلة + محادثة + صوت)
- `src/kit.tsx` مكونات الواجهة + راوتر بسيط بالـ hash
- `public/sw.js` عامل الخدمة للتشغيل أوفلاين

## التشغيل محليًا
```bash
npm install
npm run dev      # تطوير
npm run build    # نسخة النشر في dist/
```

## النشر
مجاني على Netlify: ارفع مجلد `dist/` (أو zip منه) — وده اللي حصل فعلًا.
